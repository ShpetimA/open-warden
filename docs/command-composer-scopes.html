Which commands move where

These are commands already present in the composer. Creation commands and actions on the current branch sit inside their scope without requiring another object selection.

Pull requests

Choose a PR first; its state and provider determine which actions are enabled.

Selected PR Open review tab, Open in worktree, Copy link, Comment, Submit review, Merge.
New row Create pull request.
Fold in Approve and Request changes become decisions inside Submit review.
PR screen only Edit details, Draft / Ready, Update branch, Auto-merge, Close / Reopen, Revert already exist in the PR screen. They could join this selected-PR menu later, subject to provider and state.

Branches

Choose a branch first for actions that target a different branch.

Selected branch Switch, Stash & switch, Merge into current, Rebase current onto selected, Delete merged local branch, Create worktree.
Other rows Create branch; Rename current branch.

Stashes

Choose a saved stash before deciding what to do with it.

Selected stash Apply, Pop, Delete.
New row Save stash.

Tags

The existing View tags list already opens the tagged commit in History.

Selected tag Open tagged commit, Delete local tag.
New row Create tag at HEAD.

Keep these direct

They act on the current repository or have only one useful action after selection. An extra scope step would slow them down.

Pull Push Commit Stage all Unstage all Stash staged Fetch Publish branch View incoming commits View outgoing commits Open repository Blame file Remove worktree

Worktrees: Create worktree follows a selected branch. Remove worktree keeps its existing “choose worktree → confirm” flow; it does not need a one-action Worktrees hub.

Behavior that makes the grouping useful

Search stays scoped

Root search returns scopes and direct commands. It may match a child command, but shows its parent scope as the result. Inside a scope, search the objects or actions for that scope.

Selection is context

Launching Cmd+K from an open PR can preselect that PR and start on its actions. Back returns to the PR list with the same item highlighted.

Confirm by consequence

Open review, open repository, and copy link run on selection. Merge, delete, review submission, and other changes keep a final preview or confirmation.
