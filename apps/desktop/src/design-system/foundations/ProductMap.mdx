# Product component map

Open Warden will design and approve its interface in Storybook before feature screens adopt it. Existing feature behavior remains the source of truth while this component language is developed.

## Navigation model

The proposed direction replaces the fixed bottom project selector with composable workspace tabs:

1. A **project tab** keeps a repository and its current feature context together.
2. A **pull-request tab** opens a review independently, without replacing the current project workspace.
3. Project-local tabs switch between Changes, History, Review, and Pull requests.
4. **⌘K** is the universal way to open projects, pull requests, history entries, files, and actions.
5. Tabs can be reordered, closed, restored, and overflowed without changing the underlying repository state.

Search is an entry point into these resources. Whether a search result remains a temporary view or becomes a durable workspace tab should be decided from the Storybook compositions before implementation.

## File-tree boundary

Pierre remains the file-tree and code-tree renderer. The design system owns the surrounding panel, toolbar, selection context, empty/loading/error states, and navigation chrome. It does not introduce a competing file-tree component.
